    2. Vấn đề và Kế hoạch¶

    2.1 Các vấn đề P0 ban đầu¶

    🔴 P0 — Metadata Coverage cực thấp (11.7%) — ✅ ĐÃ GIẢI QUYẾT¶

    Trước: 50/427 sidecars (11.7%). Sau Phase 1.3: 427/427 (100%). Cách làm: - MetadataExtractor giờ đọc pre-computed detections từ data/detections/{video}/{frame}.json thay vì chạy lại YOLO (load_precomputed_detections() trong pipeline/metadata.py). - CLI command aic26 pipeline extract-metadata --input data/keyframes --output data/metadata (chạy độc lập, không cần run-all).

    🔴 P0 — Detections hoàn toàn trống trong Metadata (100%) — ✅ ĐÃ GIẢI QUYẾT¶

    Trước: 50/50 sidecars có detections: []. Sau Phase 1: 377/427 (88.3%) sidecars có detections với position field. 50 còn lại là frames YOLO thực sự không detect được object nào. Cách làm: - KeyframeMetadata.detections schema giờ gồm position (3×3 grid từ pipeline/position.py). - Bbox < 5% diện tích ảnh trả về position: None (theo spec R5). - 3×3 grid: top-left | top-center | top-right | center-left | center | center-right | bottom-left | bottom-center | bottom-right.

    🔴 P0 — Scene Graph hoàn toàn trống (100%) — ⚠️ VẪN CÒN (0%)¶

    Hiện trạng: Tất cả 427 sidecars có scene_graph: []. Qwen2.5-VL model chưa bao giờ được invoke end-to-end trên K05_V004 vì: - PipelineOrchestrator.run(extract_metadata=True) vẫn pass dummy scene_graph_fn=lambda img: [] (orchestrator chưa wire real callable). - Code pipeline/scene_graph.py đã sẵn sàng (extract_scene_graph + Qwen2.5-VL-7B-Instruct 4-bit qua bitsandbytes), nhưng chưa được execute vì cần GPU ~14GB VRAM.

    Tác động: Truy vấn relational kiểu "person hold cup", "car park on street" hoàn toàn bất khả thi. Bước tiếp theo: Phase 4.1 — chạy batch Qwen2.5-VL inference thực tế trên K05_V004.

    2.2 Các vấn đề P1¶

    🟡 P1 — Scene Classification confidence thấp (70%) — ✅ ĐÃ GIẢI QUYẾT một phần¶

    Trước: 35/50 frames (70%) có scene confidence < 0.5. Sau Phase 2.2: Khi top-1 confidence < 0.3, scene được gán là "uncertain" → có fallback hợp lý. Sau Phase 2.3: Temporal smoothing với sliding window = 5 majority vote → unique scene giảm 82 → 36.

    🟡 P1 — Top-5 Scenes có duplicate category — ✅ ĐÃ GIẢI QUYẾT¶

    Cách làm (Phase 2.1): De-duplicate leaf labels bằng cách append parent path khi có collision. Ví dụ: - /p/platform/train_station_platform → train_station_platform - /p/platform/outdoor → platform (giữ nguyên vì chưa collision)

    Logic nằm trong Places365Classifier._infer_scene_group() và label-loading code.

    Phase 3: Bổ sung Modalities (P2) — 🔄 MIXED¶

    Task 3.1: Tích hợp OCR vào Metadata — ✅ HOÀN THÀNH¶

    Files: src/aic26/pipeline/ocr.py, src/aic26/pipeline/metadata.py, src/aic26/cli/main.py - Polygon bbox [[x1,y1],[x2,y2],[x3,y3],[x4,y4]] (EasyOCR output) → xyxy [x_min, y_min, x_max, y_max]. - Helper _polygon_to_xyxy() trong pipeline/ocr.py. - CLI command: aic26 pipeline merge-ocr --input data/ocr_results.csv --metadata-dir data/metadata [--video V] [--dry-run]. - KeyframeMetadata.ocr_text: list[OCRText] | None — None khi chưa merge. - Schema: {"text": str, "bbox": [x1,y1,x2,y2], "confidence": float}. - Tests: test_ocr_polygon.py (4 tests), tests trong test_cli_metadata.py (4 tests cho merge-ocr). - End-to-end: 427/427 sidecars updated, 3,139 text regions merged.

    Task 3.2: Image Captioning — ✅ HOÀN THÀNH¶

    Files mới: - src/aic26/pipeline/captioning.py — CaptionGenerator + build_caption_fn(). - tests/unit/test_captioning.py — 12 tests (mock BLIP/BLIP-2 classes ở boundary transformers.*).

    Files sửa: - src/aic26/pipeline/metadata.py — CaptionFn type alias, KeyframeMetadata.caption, MetadataStats.sidecars_with_caption, MetadataStats.caption_total_chars, build_metadata_callables() returns 4-tuple, apply_caption_merging() post-pass function. - src/aic26/cli/main.py — --skip-caption flag, merge-captions subcommand. - src/aic26/config/settings.py — caption_model_name, caption_max_new_tokens, caption_min_length, caption_quantization. - src/aic26/config/constants.py — CAPTION_DEFAULT_MODEL, CAPTION_PROMPT, CAPTION_MAX_NEW_TOKENS, CAPTION_MIN_LENGTH.

    Model đã chọn: Salesforce/blip-image-captioning-base (446M params) — KHÔNG dùng Salesforce/blip2-itm-vit-g (ITM variant — không có .generate() method, đã được document trong memory blip2-itm-g-image-only).

    Implementation: - CaptionGenerator lazy-loads model+processor trên first .generate() call. - Branches trên "blip2" in model_name.lower() để chọn BlipProcessor/BlipForConditionalGeneration (BLIP base) hoặc Blip2Processor/Blip2ForConditionalGeneration (BLIP-2). - Returns "" on any exception (graceful degradation). - Default prompt: "a photo of" (BLIP base ignores prompt nhưng wiring vẫn truyền qua processor).

    CLI: - aic26 pipeline extract-metadata --input data/keyframes --output data/metadata --skip-caption (skip flag mới). - aic26 pipeline merge-captions --input data/metadata --keyframes-dir data/keyframes [--video V] [--model-name NAME] [--dry-run].

    End-to-end: 427/427 K05_V004 sidecars updated, avg 46 chars/caption, 0 empty captions.

    4. Schema Metadata hiện tại (post-Phase 3.2)¶

    Lưu ý: KHÔNG có version field ở top-level. Backward-compat được thực hiện bằng cách chỉ emit optional fields khi populated (None thì không xuất hiện trong JSON). Đây là chiến lược khác với ban đầu đề xuất ("version": "2.0").

    {
  "video": "K05_V004",
  "frame_idx": 42,
  "detections": [
    {
      "label": "Person",
      "score": 0.92,
      "bbox": [10, 20, 100, 200],
      "position": "top-left"
    }
  ],
  "scene": {
    "category": "airport_terminal",
    "confidence": 0.633,
    "scene_group": "transportation",
    "top5": [["airport_terminal", 0.633], ["indoor", 0.185]],
    "smoothed_category": "airport_terminal"
  },
  "scene_graph": [
    {"s": "person", "p": "hold", "o": "cup", "confidence": 0.9}
  ],
  "ocr_text": [
    {"text": "EXIT", "bbox": [50, 10, 120, 40], "confidence": 0.95}
  ],
  "caption": "A person holding a cup while standing in an airport terminal."
}

    Quy tắc backward-compat: - detections: luôn emit (mặc định []). - scene: null khi chưa chạy, {...} khi đã chạy. - scene_graph: [] khi chưa chạy hoặc ran-but-empty. - ocr_text: null khi chưa merge, [{...}] sau merge. - caption: null khi chưa chạy, "" (chuỗi rỗng) khi model thất bại — phân biệt với model chưa chạy.
